# ⚡ CurrencyFlow | Premium Converter

**CurrencyFlow** is a sleek, modern, and high-performance currency converter designed for a seamless user experience. It leverages real-time market data to provide accurate exchange rates with a premium glassmorphic interface.

### 🔗 [Live Demo](https://bg-currency-converter.onrender.com)

![CurrencyFlow Preview](https://bg-currencyflow.onrender.com)

## ✨ Features

- **Real-Time Data**: Powered by the reliable [fawazahmed0/currency-api](https://github.com/fawazahmed0/currency-api).
- **Premium Design**: Modern UI with Tailwind CSS, glassmorphism, and smooth micro-animations.
- **Dynamic Flag Loading**: Automatically updates flags based on selected currencies using FlagsAPI.
- **Smart Swap**: Instantly switch between 'From' and 'To' currencies.
- **Responsive Layout**: Designed to look stunning on all devices, from mobile to desktop.
- **Instant Result**: Updates conversion as you type.

## 🚀 Tech Stack

- **Frontend**: HTML5, Tailwind CSS
- **Logic**: Vanilla JavaScript (ES6+)
- **API**: [Exchange Rate API](https://github.com/fawazahmed0/currency-api)
- **Icons**: Font Awesome 6

## 🛠️ Getting Started

Follow these steps to run the project locally on your machine.

### 1. Clone the Repository
```bash
git clone https://github.com/bhavit-gupta/currencyConverter.git
cd currencyConverter
```

### 2. Build & Run
- **Install Dependencies**:
  ```bash
  npm install
  ```
- **Build CSS**:
  ```bash
  npm run build
  ```
- **Launch**: Open `src/index.html` in your browser.
